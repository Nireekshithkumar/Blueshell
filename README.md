# BlueShells React

Install the dependencies with npm install and start Vite with npm run dev. Run npm run build to type-check and create the production site in dist. The Vite base is relative for GitHub Pages.

The homepage uses six transparent shell photographs in a reversible GSAP ScrollTrigger sequence. Desktop and mobile have different scroll distances. Reduced motion shows the open shell. The particle heading, curved marquee and chapter reveals are original free BlueShells components. Navigation uses TextRoll from the uploaded Skiper58 source. The other uploaded examples are preserved under reference/skiper.

The six tool photos and six original team portraits are bundled locally from the original BlueShells site (https://github.com/rithish4911/BlueShells). The certificate links point to the original PDFs. Registration prepares an enquiry in the visitor's email app. The visitor must send the message there.
